# Issue tracker

Issues for this repo live as **local markdown** under `.scratch/<feature>/`.
This is a solo project with no GitHub/GitLab remote, so skills like `to-issues`,
`triage`, and `qa` should create/read markdown files there rather than calling
`gh`/`glab`.

- One directory per feature/bug under `.scratch/`.
- Each issue is a markdown file with a title (H1), a body, and a triage label
  line (see triage-labels.md).
- PRs are not a request surface (no remote).
